# Question 11: Reusable Student Component (ReactJS)

## Problem Statement
Develop a ReactJS program to create a reusable Student component that accepts `student name`, `branch`, and `semester` through props and displays the details.

## Components
- `Student.jsx`: The reusable presentational component accepting `name`, `branch`, `semester`, `rollNumber`, and `email` props.
- `Program11.jsx`: Parent container rendering multiple student instances and allowing dynamic testing of prop passing.

## How to Run

```bash
# Starts the React development server:
npm run dev
# Then click on Question 11 in the sidebar!
```
