# Question 12: Simple Counter with useState (ReactJS)

## Problem Statement
Develop a ReactJS program using `useState` to implement a simple counter with **Increment**, **Decrement**, and **Reset** buttons.

## Components
- `Counter.jsx`: React component managing count state with `useState(0)` and three action buttons.

## How to Run

```bash
# Starts the React development server:
npm run dev
# Then click on Question 12 in the sidebar!
```
