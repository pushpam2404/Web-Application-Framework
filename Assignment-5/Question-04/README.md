# Question 4: ExpressJS Routing

## Problem Statement
Develop an ExpressJS application with the following routes:
- `GET /students` → Display a list of students.
- `GET /students/:id` → Display the details of a student based on ID.
- `GET /faculty` → Display faculty information.
- Implement a suitable response for an invalid route.

## How to Run

```bash
node Question-04/server.js
# Or:
npm run q4
```

Runs on port 5001.

## Endpoints
- `GET http://localhost:5001/students`
- `GET http://localhost:5001/students/1`
- `GET http://localhost:5001/faculty`
- `GET http://localhost:5001/invalid`
