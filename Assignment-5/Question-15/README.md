# Question 15: Employee Management Application (ReactJS)

## Problem Statement
Develop a ReactJS Employee Management application using components, props, and Hooks:
- Display employee details.
- Implement functionality to add a new employee.
- Implement functionality to update an existing employee's information.

## Components
- `EmployeeItem.jsx`: Child component rendering single employee row with edit & delete actions.
- `EmployeeForm.jsx`: Reusable form component supporting both addition and in-place editing.
- `EmployeeManagement.jsx`: Parent container managing employees state and edit workflow.

## How to Run

```bash
# Starts the React development server:
npm run dev
# Then click on Question 15 in the sidebar!
```
