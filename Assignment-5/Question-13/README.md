# Question 13: Product List with useState and useEffect (ReactJS)

## Problem Statement
Develop a ReactJS program using `useState` and `useEffect` to maintain a list of products and display a message whenever the product list is modified.

## Components
- `ProductList.jsx`: React component maintaining products array via `useState`, listening to changes using `useEffect(..., [products])`, and displaying interactive notifications and log history.

## How to Run

```bash
# Starts the React development server:
npm run dev
# Then click on Question 13 in the sidebar!
```
