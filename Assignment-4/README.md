# Assignment 4 - ReactJS

10 ReactJS lab programs (see `Assignment 4-WAF.pdf` for the questions), built with Vite + React.

Each program is a separate component in `src/Program1.jsx` through `src/Program10.jsx`, and `src/App.jsx` provides a sidebar to switch between them.

## Setup

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser and use the sidebar to switch between programs.

## Programs

1. Welcome message with student name and department (functional component + JSX)
2. Student info passed as props from parent to child
3. Counter with useState (Increment / Decrement / Reset)
4. Controlled form for name and email
5. Digital clock with useEffect and cleanup
6. Fetches and displays users from a public API, with loading/error states
7. Light/Dark theme switcher using Context API
8. Shopping cart with Add/Remove using useState and props
9. Student attendance management using Context API + useReducer
10. Task manager using Context API, useState, and useEffect
